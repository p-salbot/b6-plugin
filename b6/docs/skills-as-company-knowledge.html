Skill je textový súbor pre AI asistenta. Postup si AI často vymyslí sama; fakty o firme si zvyčajne vymyslieť nevie.

01 — Ako AI skill číta
Popis
AI ho spravidla vidí stále.
Telo
AI ho otvorí, keď popis sedí na úlohu.
Podklady
Rozsiahlejšie materiály sa otvárajú, až keď sú potrebné. Dlhý číselník prehľadá malý program.
O tom, či sa skill otvorí, rozhoduje popis. Preto má obsahovať slová, ktoré ľudia naozaj používajú.

Skills as company knowledge

A skill does not have to be a procedure. It can carry what the company knows.

A skill is a text file for an AI assistant. The AI can often work out a procedure for itself; it usually cannot work out the company's own facts.

01 — How the AI reads a skill
Description
The AI normally sees it all the time.
Body
The AI opens it when the description matches the task.
Reference material
Larger material is opened only when needed. A long code list is looked up by a small program.
The description decides whether the skill is opened. It should therefore contain the words people really use.
02 — The two main kinds of skill
How to do something
Procedure
Steps, commands and templates for one recurring task.
Like a work instruction.
Improves one task.
What is true
Knowledge map
Facts, terms, rules, traps and open questions of one domain.
Like an experienced colleague sitting next to you.
Can improve many tasks in its domain.
Glossary — the company's terms, abbreviations and codes, each with one meaning.
Personal profile — a person's role, real skills and working style.
03 — What keeps a skill correct
1
The AI drafts, the person adds and approves.
2
The skill is used daily.
3
Whoever notices an error says so right in the conversation.
4
The owner corrects it and reviews it regularly.
and round again
Skills guide; they do not enforce. A line that must never be crossed is protected by access rights and technical blocks.
