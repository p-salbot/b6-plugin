Cowork a Claude Code

Oba bežia na tom istom Claude a oba vedia pracovať s tvojimi súbormi, skillmi a pluginmi. Líšia sa tým, kde práca beží, kde sa veci ukladajú a koľko od teba očakávajú. Tento sprievodca ukazuje, kde v Claude Code nájdeš to, čo poznáš z Cowork, a pomôže rozhodnúť, čo sa ku komu hodí.

Claude Code tu znamená záložku Code v desktop aplikácii Claude. Verzia v termináli (CLI) má rovnaké nastavenia a spomína sa iba tam, kde vie niečo, čo desktop aplikácia nevie.

Dve pracoviská, jeden Claude

Cowork

Na kancelársku prácu, bez terminálu

Dokumenty, tabuľky, prieskum, reporty. Pripojíš priečinky a aplikácie, opíšeš úlohu a Claude ju vykoná. Práca beží v izolovanom prostredí na serveroch Anthropic. Cez desktop aplikáciu číta a zapisuje do priečinkov, ktoré si pripojil.

Claude Code

Na prácu so súbormi, skriptmi a kódom

Otvoríš priečinok na svojom počítači a Claude pracuje priamo v ňom: číta súbory, spúšťa skripty a príkazy, verzie drží v gite. Lokálna session beží na tvojom počítači. Môže bežať aj v cloude alebo na inom počítači.

Podrobnosti

Jedno miesto pre jednu prácu

Cowork

Projekt združuje súvisiace úlohy s vlastnými inštrukciami, kontextom a pamäťou. Vytvoríš ho v aplikácii a pomenuješ.

Claude Code

Objekt „projekt“ tu nie je. Projekt je priečinok, ktorý vyberieš pod poľom na správu pred prvou správou. Všetko, čo Claude k práci potrebuje, je v ňom ako obyčajné súbory, ktoré môžeš otvoriť, skopírovať a zálohovať.

Projekty sú iba v Cowork; Claude Code projekty z Cowork nevidí. Kde Cowork projekt ukladá (na počítači alebo v účte), opisujú stránky Anthropic rôzne over v aplikácii.

Stále pravidlá: inštrukcie a CLAUDE.md

Cowork

Globálne inštrukcie (Settings → Cowork, v novších verziách „Instructions for Claude“) platia pre každú úlohu. Inštrukcie projektu platia pre úlohy v jednom projekte. Inštrukcie priečinka dopĺňajú kontext k pripojenému priečinku; Claude ich môže počas úlohy sám upraviť.

Claude Code

CLAUDE.md je obyčajný textový súbor v priečinku projektu. Claude ho prečíta na začiatku každej session. Tvoj osobný CLAUDE.md je v tvojom používateľskom priečinku (pozri Kde sú tieto súbory) a platí v každom projekte. Oba sa upravujú ako každý iný súbor, tebou alebo Claudom, keď ho o to požiadaš.

Na oboch miestach drž iba to, čo platí vždy. Postup pre jeden druh úlohy patrí do skillu.

Dokumenty, z ktorých má Claude čerpať

Cowork

Kontext projektu tvoria pripojené lokálne priečinky, odkazy a prepojené chat projekty (s dokumentmi, ktoré sú do nich nahrané). Claude číta súbory z pripojených priečinkov do 50 MB na súbor. K lokálnym priečinkom sa dostane, iba keď je desktop aplikácia otvorená.

Claude Code

Dokumenty sú súbory v priečinku projektu. Na začiatku sa načíta iba CLAUDE.md; ostatné súbory sa otvoria, keď ich práca potrebuje. Malý súbor, ktorý treba čítať zakaždým, sa dá vložiť do CLAUDE.md riadkom ako @docs/pravidla.md.

V Claude Code môže skill alebo inštrukcia odkázať na presný súbor (ceny/2026.xlsx) a skript z neho prečíta každý riadok. V Cowork odkazuj na dokument menom a tým, čo obsahuje.

Čo si Claude pamätá

Cowork

Každý projekt má vlastnú pamäť; čo sa Claude naučí v jednom projekte, do iného neprejde. Projekt predvolene používa aj pamäť tvojho účtu z chatov; na stránke projektu sa to dá vypnúť („Use account memory“).

Claude Code

Claude si medzi session nepamätá nič okrem toho, čo je zapísané. Spoľahlivá pamäť sú vlastné dokumenty projektu: CLAUDE.md, požiadavky, úlohy a plány (pozri sprievodcu Project memory). Automatická pamäť pridáva krátke poznámky, ktoré si Claude vedie ku každému projektu na tvojom počítači.

Skilly a čo znamená .claude/skills

Skill je priečinok so súborom SKILL.md: hore krátky popis, pod ním postup. Môže obsahovať ďalšie súbory, ktoré postup používa (šablóny, príklady, skripty). Claude vidí iba popisy všetkých skillov; celý skill otvorí, keď popis sedí na tvoju požiadavku.

Ten istý skill môže byť na troch miestach. Ktoré miesta prostredie vidí, rozhoduje o tom, kde skill funguje:

Pluginy a konektory

Cowork

Customize → Plugins: prehliadať a inštalovať, pridať marketplace cez URL alebo GitHub owner/repo, prípadne nahrať súbor. Plugin sa uloží do tvojho účtu, takže jeho skilly a konektory máš aj v chate a v Claude Code. Konektory sú v Customize → Connectors, s povolením pre každý nástroj.

Claude Code

Tlačidlo + vedľa poľa na správu → Plugins. Plugin sa dá nainštalovať pre tvoj používateľský účet, pre jeden projekt alebo iba lokálne. Pluginy fungujú v lokálnych a SSH session, nie v cloudových. Konektory sa pridávajú tiež cez +.

Plugin je balík: skilly, konektory, agenti (pomocníci s vlastným kontextom) a hooky (akcie v pevných momentoch). Administrátor organizácie (Team, Enterprise) môže pluginy nastaviť ako predvolene nainštalované, dostupné, nedostupné alebo povinné.

Agentová práca: Claude urobí viac krokov a časti odovzdá pomocníkom

Cowork

Zadáš cieľ; Claude naplánuje kroky, zložitú prácu rozdelí na menšie úlohy a sám koordinuje subagentov. Akcie schvaľuješ podľa režimu. Práca beží v cloude, takže dlhá úloha nezávisí od tvojho počítača (iba prístup k lokálnym priečinkom potrebuje otvorenú desktop aplikáciu). Vlastných agentov môžu pridať pluginy.

Claude Code

Agent je pomocník s vlastným čistým kontextom: dostane zadanie, urobí svoju časť a vráti krátku správu, takže hlavný chat zostane malý. Zabudovaných agentov (napríklad na vyhľadávanie) Claude používa sám, ďalších pridávajú pluginy (b6 pridáva worker a reviewer) a vlastného agenta si môžeš napísať ako súbor v .claude\agents\ projektu alebo svojho používateľského priečinka. Dlhé príkazy môžu bežať na pozadí a viac session môže pracovať súbežne.

Oba sú agentové: Claude vykoná viac krokov bez toho, aby si ho viedol pri každom. Rozdiel je v kontrole. V Claude Code vidíš a rozhoduješ, kto čo robí, napríklad pravidlo b6, že každý krok skontroluje nový recenzent. Tímy agentov (viac agentov spolupracuje na jednej úlohe) sú iba vo verzii v termináli.

Kde práca beží a čo smie Claude

Cowork

Kód a príkazy bežia v izolovanom prostredí na serveroch Anthropic. Claude číta a zapisuje iba do priečinkov, ktoré si pripojil. Schvaľovanie: Manual (pýta sa), Auto (akcie posudzuje automatická kontrola), Skip (bez kontrol). Mazanie vždy potrebuje tvoje povolenie.

Claude Code

Lokálna session beží na tvojom počítači s priamym prístupom k vybranému priečinku a k tomu, kam sa dostane tvoj používateľský účet. Cloudové a SSH session bežia inde. Režimy: Manual, Accept edits, Plan (navrhuje, nemení), Auto, Bypass (bez otázok; najprv sa musí povoliť v nastaveniach, nie na každom pláne).

Lokálna session Claude Code môže na tvojom počítači urobiť čokoľvek, čo môžeš ty, v rámci zvoleného režimu. Preto sa hodí ľuďom, ktorí rozumejú, čo príkaz alebo skript robí, skôr než ho schvália.

Predchádzajúca a opakovaná práca

Cowork

Úlohy zostávajú v projekte a v bočnom paneli. Naplánované úlohy (/schedule alebo Scheduled v bočnom paneli) bežia v cloude, aj keď je tvoj počítač vypnutý, a preberajú inštrukcie a pamäť projektu.

Claude Code

Session sú v bočnom paneli; dajú sa premenovať, zoskupiť a archivovať. Dlhá session sa spomaľuje; na novú úlohu začni novú (pozri What loads when). Opakovaná práca beží ako rutiny v cloude.

Zdieľanie s tímom

Cowork

Organizácia zdieľa pluginy a skilly cez nastavenia administrátora. Či sa dá zdieľať samotný projekt Cowork, opisujú stránky Anthropic rôzne over v aplikácii. Artefakty (stránky, ktoré Claude vytvoril) sa zdieľať dajú.

Claude Code

Projekt je priečinok, takže sa zdieľa ako súbory: git repozitár, zdieľaný disk alebo plugin pre skilly, ktoré používa viac ľudí. Všetci potom majú rovnaký CLAUDE.md a skilly projektu.

Iba v Claude Code

  • História verzií. S gitom sa dá každá zmena pozrieť a vrátiť.
  • Kontrola zmien. Karta Changes ukáže každý zmenený riadok; k riadku môžeš napísať komentár a Claude ho opraví.
  • Vlastné skripty. Python alebo iné skripty bežia na tvojom počítači, nad tvojimi súbormi, zakaždým s rovnakým výsledkom.
  • Hooky vo vlastných nastaveniach, nielen z pluginov.
  • Súbežné session v samostatných kópiách projektu (worktrees, potrebuje git).
  • Iba vo verzii v termináli: skriptované behy bez okna (na automatizáciu) a tímy agentov.

Čo kedy

Rozhoduje skôr človek než úloha: jeho technické zručnosti a to, ako rozumie skillom. Človeka posuň o úroveň vyššie, keď splní podmienku na konci svojej úrovne.

1

Chat a projekty v Cowork

Pracuje s dokumentmi a tabuľkami, zadáva jasné úlohy. Používa projekty s inštrukciami a pripojenými priečinkami.

Ďalšia úroveň, keď: opakuje tie isté inštrukcie vo viacerých úlohách a vie postup opísať krok za krokom.

2

Vlastné skilly v Cowork

Opakovaný postup premení na skill v účte, popis píše slovami, ktoré ľudia naozaj používajú, inštaluje pluginy, ktoré organizácia ponúka.

Ďalšia úroveň, keď: práca potrebuje presné súbory, skripty alebo veľa riadkov dát spracovaných zakaždým rovnako a priečinky a cesty k súborom mu nerobia problém.

3

Claude Code v desktop aplikácii

Otvorí priečinok, drží v ňom CLAUDE.md a skilly projektu, pred schválením si prečíta, čo chce Claude spustiť, zmeny kontroluje po riadkoch.

Ďalšia úroveň, keď: stavia nástroje pre iných a chce metódu s požiadavkami, plánmi a kontrolami.

4

Claude Code s pluginom b6

Stavia a mení nástroje po krokoch: dohodnuté požiadavky, plán, malé kroky, ktoré robí worker a kontroluje nový reviewer, s gitom. Pozri Getting started with b6.

Skill, ktorý funguje v oboch

  • Daj ho do svojho účtu (nahraj ho alebo nainštaluj s pluginom). Skilly v účte sa načítajú v Cowork aj v Claude Code, lokálne aj v cloude.
  • Stály obsah nos v skille. Šablóny, zoznamy kódov a vzorové výstupy patria do priečinka skillu (napríklad references/), nie do kontextu projektu.
  • Na meniace sa dokumenty odkazuj menom a obsahom, napríklad „aktuálny cenník (tabuľka materiálov s cenou za kus)“, a pridaj záložný krok: „ak nie je k dispozícii, vypýtaj si ho od používateľa“.
  • Žiadne pevné cesty. Cesta ako C:\Users\… existuje iba na jednom počítači a v Cowork nikdy.
  • Slabé miesto sú skripty. V Claude Code bežia na tvojom počítači nad tvojimi súbormi; v Cowork bežia v cloudovom prostredí nad pripojenými priečinkami. Píš ich tak, aby súbor dostali ako vstup, a skill pred odovzdaním vyskúšaj v oboch.

Cowork and Claude Code

Both run on the same Claude and both can work with your files, skills and plugins. They differ in where the work runs, where things are stored and how much they expect you to know. This guide shows where to find in Claude Code what you know from Cowork, and helps you decide which one fits a person.

Claude Code here means the Code tab of the Claude desktop app. The terminal version (CLI) shares the same settings and is mentioned only where it can do something the desktop app cannot.

Two workplaces, one Claude

Cowork

For office work, no terminal

Documents, spreadsheets, research, reports. You connect folders and apps, describe the task and Claude carries it out. The work runs in an isolated environment on Anthropic's servers. Through the desktop app it reads and writes the folders you connected.

Claude Code

For work with files, scripts and code

You open a folder on your computer and Claude works directly in it: reads files, runs scripts and commands, keeps versions in git. A local session runs on your computer. It can also run in the cloud or on another machine.

Details

One place for one piece of work

Cowork

A project groups related tasks with their own instructions, context and memory. You create it in the app and give it a name.

Claude Code

There is no project object. The project is the folder you choose under the message box before your first message. Everything Claude needs for the work is in that folder as ordinary files you can open, copy and back up.

Projects are a Cowork feature only; Claude Code does not show Cowork projects. Where Cowork stores a project (on the computer or in the account) is described differently in Anthropic's pages check in your app.

Standing rules: instructions and CLAUDE.md

Cowork

Global instructions (Settings → Cowork, or "Instructions for Claude" in newer versions) apply to every task. Project instructions apply to tasks in one project. Folder instructions add context for a connected folder; Claude may update them itself during a task.

Claude Code

CLAUDE.md is a plain text file in the project folder. Claude reads it at the start of every session. Your personal CLAUDE.md is in your user folder (see Where these files are) and applies in every project. Both are edited like any other file, by you or by Claude when you ask.

Keep in both places only what is always true. A procedure for one kind of task belongs in a skill.

Documents Claude should use

Cowork

Project context is made of connected local folders, links and linked chat projects (with the documents uploaded to them). Claude reads files from connected folders up to 50 MB each. The desktop app must be open for Claude to reach local folders.

Claude Code

Documents are files in the project folder. Only CLAUDE.md is loaded at the start; other files are opened when the work needs them. A small file that must be read every time can be pulled into CLAUDE.md with a line like @docs/rules.md.

In Claude Code a skill or an instruction can point to an exact file (prices/2026.xlsx) and a script can read every row of it. In Cowork, refer to a document by its name and what it contains.

What Claude remembers

Cowork

Each project has its own memory; what Claude learns in one project does not carry over to another. By default a project also uses your account memory from chats; you can turn this off on the project page ("Use account memory").

Claude Code

Claude remembers nothing between sessions except what is written down. The reliable memory is the project's own documents: CLAUDE.md, requirements, tasks and plans (see the Project memory guide). Automatic memory adds short notes Claude keeps per project on your computer.

Skills, and what .claude/skills means

A skill is a folder with a file SKILL.md: a short description at the top and a procedure below it. It may hold more files the procedure uses (templates, examples, scripts). Claude sees only the descriptions of all skills; it opens the whole skill when a description fits your request.

The same skill can live in three places. Which places an environment sees decides where the skill works:

Where these files are on your computer

  • The dot hides the folder. A name starting with a dot (.claude) is a hidden folder. In Windows 11 File Explorer: View → Show → Hidden items. On a Mac in Finder: Cmd + Shift + .
  • The quickest way in Windows: type %USERPROFILE%\.claude into the address bar of File Explorer and press Enter.
  • Adding a personal skill means copying its folder into .claude\skills\, so that the path is .claude\skills\<skill name>\SKILL.md. A new session sees it.
  • Your personal CLAUDE.md is %USERPROFILE%\.claude\CLAUDE.md.

Plugins and connectors

Cowork

Customize → Plugins: browse and install, add a marketplace by URL or GitHub owner/repo, or upload a file. A plugin is saved to your account, so its skills and connectors are also available in chat and in Claude Code. Connectors are in Customize → Connectors, with a permission per tool.

Claude Code

The + button next to the message box → Plugins. A plugin can be installed for your user account, for one project or only locally. Plugins work in local and SSH sessions, not in cloud sessions. Connectors are added through + as well.

A plugin is a package: skills, connectors, agents (helpers with their own context) and hooks (actions at fixed moments). An organization admin (Team, Enterprise) can set plugins as installed by default, available, not available or required.

Agentic work: Claude does several steps and hands parts to helpers

Cowork

You give the goal; Claude plans the steps, splits complex work into smaller tasks and coordinates sub-agents itself. You approve actions according to the mode. The work runs in the cloud, so a long task does not depend on your computer (only access to local folders needs the desktop app open). Plugins can add their own agents.

Claude Code

An agent is a helper with its own fresh context: it gets a brief, does its part and returns a short report, so the main chat stays small. Claude uses built-in agents (for example for searching) on its own, plugins add more (b6 adds worker and reviewer), and you can write your own as a file in .claude\agents\ of the project or of your user folder. Long commands can run in the background and several sessions can work side by side.

Both are agentic: Claude carries out several steps without you guiding each one. The difference is control. In Claude Code you see and decide who does what, for example b6's rule that a fresh reviewer checks every step. Agent teams (several agents working together on one task) are available only in the terminal version.

Where the work runs and what Claude may do

Cowork

Code and commands run in an isolated environment on Anthropic's servers. Claude reads and writes only the folders you connected. Approvals: Manual (asks), Auto (an automatic check reviews actions), Skip (no checks). Deleting always needs your permission.

Claude Code

A local session runs on your computer with direct access to the chosen folder and to what your user account can reach. Cloud and SSH sessions run elsewhere. Modes: Manual, Accept edits, Plan (proposes, does not change), Auto, Bypass (no questions; must be allowed in Settings first, not on every plan).

A local Claude Code session can do anything you can do on your computer, within the mode you chose. That is why it suits people who understand what a command or script does before they approve it.

Earlier work and repeating work

Cowork

Tasks stay in the project and the sidebar. Scheduled tasks (/schedule or Scheduled in the sidebar) run in the cloud without your computer being on and inherit the project's instructions and memory.

Claude Code

Sessions are listed in the sidebar; you can rename, group and archive them. A long session gets slower; start a new one for a new task (see What loads when). Repeating work runs as routines in the cloud.

Sharing with the team

Cowork

The organization shares plugins and skills through the admin settings. Whether a Cowork project itself can be shared is described differently in Anthropic's pages check in your app. Artifacts (pages Claude made) can be shared.

Claude Code

The project is a folder, so it is shared like files: a git repository, a shared drive, or a plugin for skills that more people use. Everyone then has the same CLAUDE.md and project skills.

Only in Claude Code

  • Version history. With git every change can be seen and undone.
  • Review of changes. The Changes card shows each changed line; you can comment on a line and Claude fixes it.
  • Your own scripts. Python or other scripts run on your computer, over your files, with the same result every time.
  • Hooks in your own settings, not only from plugins.
  • Parallel sessions in separate copies of the project (worktrees, needs git).
  • Only in the terminal version: scripted runs without a window (for automation) and agent teams.

Which one when

The person decides it more than the task: their technical skills and how well they understand skills. Move a person one level up when they meet the condition at the end of their level.

1

Chat and Cowork projects

Works with documents and spreadsheets, writes clear tasks. Uses projects with instructions and connected folders.

Next level when: they repeat the same instructions in several tasks and can describe the procedure step by step.

2

Own skills in Cowork

Turns a repeated procedure into a skill in the account, keeps the description in words people really use, installs plugins the organization offers.

Next level when: the work needs exact files, scripts or many rows of data processed the same way every time, and they are comfortable with folders and file paths.

3

Claude Code in the desktop app

Opens a folder, keeps CLAUDE.md and project skills there, reads what Claude wants to run before approving it, reviews changes line by line.

Next level when: they build tools for others and want a method with requirements, plans and checks.

4

Claude Code with the b6 plugin

Builds and changes tools step by step: agreed requirements, a plan, small steps done by a worker and checked by a fresh reviewer, with git. See Getting started with b6.

A skill that works in both

  • Put it in your account (upload it or install it with a plugin). Account skills load in Cowork and in Claude Code, local and cloud.
  • Carry fixed content inside the skill. Templates, lists of codes and sample outputs go into the skill folder (for example references/), not into project context.
  • Refer to changing documents by name and content, for example "the current price list (a table of materials with prices per piece)", and add a fallback: "if it is not available, ask the user for it".
  • No fixed paths. A path like C:\Users\… exists only on one computer and never in Cowork.
  • Scripts are the weak spot. In Claude Code they run on your computer over your files; in Cowork they run in the cloud environment over connected folders. Write them so they take the file as an input, and try the skill in both before you hand it over.
