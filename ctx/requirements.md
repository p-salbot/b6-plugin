# Požiadavky

## Zámer

Plugin `b6` pre Claude Code dáva firme spoločný postup, ako stavať riešenia: od nápadu cez schválené požiadavky, plán
a prácu agentov `worker` a `reviewer` po zdokumentované uzavretie. Je pre ľudí, ktorí v Claude Code stavajú a nie sú
programátori. Rieši, že Claude uteká do implementácie, výsledok sa nekontroluje voči tomu, čo človek chcel, a zbytočne
sa míňajú tokeny.

## Mimo rozsahu

- 2026-11-14: ďalšie roly agentov (analytik, tester, dokumentarista, prieskumník), paralelné vlny, práca v cloude, Cowork.
- 2026-11-14: vizuálny sprievodca zo superpowers a skúšobné stavby (spike).
- 2026-11-14: aplikácie a procesy klienta; plugin neobsahuje údaje klienta.
- 2026-11-14: prerobenie staršieho balíka `orchestracia`; ostáva na mieste a označí sa ako nahradený.
- 2026-11-14: automatický prevod `ctx/` zo starého balíka `orchestracia`.
